# ITCO603 Systems Analysis and Design

Interactive course site for ITCO603 at United Arab Emirates University.

The site connects important concepts to stakeholder evidence, requirements, models, mockups, usability testing, practice questions, and case-based problem solving.

## GitHub Pages

Publish the `docs` folder from the `main` branch.

## Local preview

Open `docs/index.html` directly or serve the `docs` directory with any static web server.
